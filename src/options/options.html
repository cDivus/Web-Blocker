Help & Syntax Guide

Learn how to write custom block rules, time limits, and exceptions.

Supported Rule Formats
Format / Example Description
facebook.com Standard Block: Blocks the domain and all of its subdomains (e.g. blog.facebook.com).
youtube.com; 15 Daily Time Limit: Grants 15 minutes of daily browse time. Blocks site once limit expires (resets at midnight).
reddit.com, twitter.com; 30 Combined Daily Limit: Shares a single 30-minute daily timer pool across multiple domains.
youtube.com/shorts Specific Path Block: Blocks specific subpaths while allowing the rest of the website.
.pdf File Extension Filter: Blocks all files or URLs ending with .pdf.
.xyz TLD Extension Filter: Blocks any website registered under the .xyz top-level domain.
gaming Keyword Block: Blocks any URL containing the word "gaming". Works with search URLs.
!music.youtube.com
!https://www.reddit.com/r		 Allowlist Exception: Overrides block rules with a ! prefix to explicitly allow specific subdomains or page subpaths (e.g. block reddit.com but allow !https://www.reddit.com/r).
# note or comment Comments: Lines or text after # are ignored so you can add notes to your block list.
